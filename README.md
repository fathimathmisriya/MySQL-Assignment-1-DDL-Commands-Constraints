# MySQL Assignment 1 – DDL Commands & Constraints

### Description
This assignment focuses on creating and managing an Employee Database using MySQL.

### Topics Covered
- Database and Table Creation
- ALTER, RENAME, TRUNCATE and DROP commands
- Applying Database Constraints
- Inserting and Retrieving Records
- Testing Constraints

### Learning Outcome
Gained practical experience in writing SQL queries, managing tables and applying constraints to maintain data accuracy.
